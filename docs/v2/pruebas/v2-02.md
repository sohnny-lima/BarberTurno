## Hallazgo para el arquitecto

El encargo exige simultáneamente:

1. `MembresiaRepository` extiende `RepositorioTransaccional`.
2. Todas las consultas de membresía reciben `negocioId` explícito.
3. `membresia` no tiene RLS (V2-DA-24).
4. Con contexto A, ningún servicio ni repositorio devuelve membresías de B (CB-5).

La implementación predeterminada que se hereda del punto 1 no cumple los puntos 2 y 4 sin una protección adicional. `RepositorioTransaccional<T, ID>` extiende `JpaRepository<T, ID>` y solo redeclara transacciones de escritura. No elimina ni filtra `findAll()`, `findById(ID)`, `findAllById`, consultas paginadas/ordenadas/por ejemplo o referencias por identidad. También expone operaciones como `deleteAllInBatch()` sin ámbito. Las anotaciones transaccionales no incorporan un predicado de negocio.

La comprobación sobre el JAR local efectivo de Spring Data JPA **4.1.1**, sin red ni base de datos, confirma:

```text
public java.util.List<T> findAll();
  Specification.unrestricted()
  Sort.unsorted()
  getQuery(...)
  TypedQuery.getResultList()

public java.util.Optional<T> findById(ID);
  EntityManager.find(Class, Object)

public void deleteAllInBatch();
  EntityManager.createQuery(deleteAllQueryString)
  Query.executeUpdate()
```

Inferencia: una entidad de membresía ordinaria, sin RLS ni otra restricción, conserva esas operaciones globales aunque todas las consultas nuevas con `@Query` reciban negocio explícito. La fijación de `app.negocio_id` y `GuardaTransaccionHibernate` de V2-01 no filtran una tabla sin políticas. Por ejemplo, una llamada heredada `membresias.findAll()` dentro de una transacción válida de A no añade una condición que excluya B. La misma superficie incluye borrados que requieren protección; no basta revisar únicamente los nuevos métodos de lectura.

**Límite de la comprobación:** no se ejecutó este ejemplo contra PostgreSQL, no se reprodujo una fuga HTTP y el repositorio nuevo no queda en la rama. Es un hallazgo de la superficie predeterminada del diseño solicitado, no una afirmación de vulnerabilidad explotada en el producto actual. Ninguna operación de borrado se ejecutó.

Se registra el bloqueo para que el coordinador concrete el tratamiento de **toda** la superficie heredada: una interfaz restringida para plataforma, o el rechazo explícito y completo de operaciones sin ámbito.
