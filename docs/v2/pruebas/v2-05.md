### Paso 5 · Parada obligatoria por H-085-01

**H-085-01 — Una ruta global con codificación porcentual evita el rechazo del prefijo de negocio.** Reproducción con MockMvc, sesión JWT válida, una cuenta PROPIETARIO de A y dos negocios reales de prueba. Petición construida con `URI.create` para conservar la codificación original, sin que el constructor de URI la escape de nuevo:

```http
GET /api/n/a/%70erfil
Cookie: BT_SESION=<sesión ficticia válida de la prueba; no se conserva el valor>
```

**Esperado:** 404 NO_ENCONTRADO, como `/api/n/a/perfil` (backlog §8.1). **Obtenido:** 200. El control literal pasa, pero no cubre la forma codificada. La regresión queda en `ResolucionNegocioIT.identidadConSegmentosCodificados_tampocoPuedeEjecutarseBajoUnNegocio`, con expectativa correcta 404, sin relajar aserciones. Incluye también `%61uth/sesion` y `%6dis-negocios`, pero el bucle se detiene en la primera aserción fallida: **solo `%70erfil` se presenta como bypass demostrado**, no las otras variantes.

Comando posterior a detener completamente la suite en curso:

```powershell
$env:JAVA_HOME = 'C:\Program Files\Eclipse Adoptium\jdk-21.0.8.9-hotspot'
.\mvnw.cmd '-Dtest=ResolucionNegocioIT#identidadConSegmentosCodificados_tampocoPuedeEjecutarseBajoUnNegocio' test
```

Salida relevante exacta (37,197 s; 10:05:17 -05:00):

```text
java.lang.AssertionError: Status expected:<404> but was:<200>
[ERROR] ResolucionNegocioIT.identidadConSegmentosCodificados_tampocoPuedeEjecutarseBajoUnNegocio:12 Status expected:<404> but was:<200>
[ERROR] Tests run: 1, Failures: 1, Errors: 0, Skipped: 0
[INFO] BUILD FAILURE
```

**Causa en esta implementación:** ResolutorNegocio toma getRequestURI, divide y compara el resto crudo con `auth`, `perfil` y `mis-negocios` (líneas 63–77 y esGlobal). Spring compara los segmentos decodificados: `%70erfil` es `perfil`. Por tanto, la cadena autoriza y MVC alcanza el controlador global que el resolutor debía rechazar. Por el flujo de código, el holder conserva A durante ese controlador; esto es una inferencia del código y de la respuesta HTTP, no una lectura instrumentada del GUC en esta regresión. No se afirma acceso a una cuenta ajena ni fuga de datos de B: lo demostrado es la violación del límite global/negocio para una cuenta propia ficticia.

Referencia primaria: [PathContainer.PathSegment.valueToMatch, Spring 7.0.9](https://docs.spring.io/spring-framework/docs/7.0.9/javadoc-api/org/springframework/http/server/PathContainer.PathSegment.html): la comparación de segmentos usa su valor decodificado y saneado. El cortafuegos previo no basta para asumir que getRequestURI ya tiene esa representación. No se debe quitar ni adelantar el resolutor al cortafuegos.

import org.springframework.jdbc.core.JdbcTemplate;
import org.springframework.test.annotation.DirtiesContext;
import org.springframework.transaction.annotation.Transactional;
import static org.assertj.core.api.Assertions.assertThat;

/** Diagnóstico del bloqueo de V2-05; toda escritura termina en rollback de la prueba. */
@SpringBootTest(properties = {"spring.datasource.hikari.maximum-pool-size=1",
        "spring.datasource.hikari.minimum-idle=1", "barberturno.admin.correo=",
        "barberturno.admin.password=", "barberturno.admin.nombre="})
@DirtiesContext(classMode = DirtiesContext.ClassMode.AFTER_CLASS)
class DiagnosticoFichasActivasIT {
    @Autowired JdbcTemplate jdbc;

    @Test
    @Transactional
    void vinculo_noDistingueFichaActivaYGlobalNoPuedeConsultarCliente() {
        assertThat(jdbc.queryForObject("select current_database()", String.class))
                .isEqualTo("barberturno_v2_test");
        assertThat(jdbc.queryForObject("select current_user", String.class))
                .isEqualTo("barberturno_v2_app");
        assertThat(jdbc.queryForObject("""
                select rolsuper or rolbypassrls or rolcreatedb or rolcreaterole or rolreplication
                from pg_roles where rolname=current_user
                """, Boolean.class)).isFalse();
        assertThat(jdbc.queryForObject("""
                select count(*) from pg_class
                where relowner=(select oid from pg_roles where rolname=current_user)
                """, Integer.class)).isZero();
        assertThat(jdbc.queryForObject("""
                select relrowsecurity and relforcerowsecurity
                from pg_class where oid='cliente'::regclass
                """, Boolean.class)).isTrue();
        assertThat(jdbc.queryForList("""
                select column_name from information_schema.columns
                where table_schema='public' and table_name='vinculo_cliente'
                order by ordinal_position
                """, String.class)).containsExactly("negocio_id", "usuario_id");

        jdbc.queryForObject("select set_config('app.negocio_id', '1', true)", String.class);
        long cuenta = jdbc.queryForObject("""
                insert into usuario (nombre, correo, telefono, password_hash, rol,
                    privacidad_aceptada_en, creado_en, actualizado_en)
                values ('Cliente ficticio diagnóstico', ?, '999999999', 'sin-login', 'CLIENTE',
                    CURRENT_TIMESTAMP, CURRENT_TIMESTAMP, CURRENT_TIMESTAMP) returning id
                """, Long.class, "diagnostico-v205-" + UUID.randomUUID() + "@ejemplo.test");
        long ficha = jdbc.queryForObject("""
                insert into cliente (usuario_id, nombre, telefono, privacidad_aceptada_en,
                    creado_en, actualizado_en)
                values (?, 'Ficha ficticia diagnóstico', '999999999', CURRENT_TIMESTAMP,
                    CURRENT_TIMESTAMP, CURRENT_TIMESTAMP) returning id
                """, Long.class, cuenta);
        assertThat(jdbc.queryForObject("select activo from cliente where id=?", Boolean.class, ficha)).isTrue();
        assertThat(jdbc.queryForObject("select count(*) from membresia where usuario_id=?", Integer.class, cuenta)).isZero();
        var vinculosActiva = jdbc.queryForList("select * from vinculo_cliente where usuario_id=?", cuenta);
        assertThat(vinculosActiva).hasSize(1);

        jdbc.queryForObject("select set_config('app.negocio_id', '', true)", String.class);
        assertThat(jdbc.queryForObject("""
                select count(*) from cliente where usuario_id=? and activo
                """, Integer.class, cuenta)).isZero();
        assertThat(jdbc.queryForList("select * from vinculo_cliente where usuario_id=?", cuenta))
                .isEqualTo(vinculosActiva);

        jdbc.queryForObject("select set_config('app.negocio_id', '1', true)", String.class);
        assertThat(jdbc.update("update cliente set activo=false where id=?", ficha)).isEqualTo(1);
        assertThat(jdbc.queryForObject("select activo from cliente where id=?", Boolean.class, ficha)).isFalse();
        assertThat(jdbc.queryForList("select * from vinculo_cliente where usuario_id=?", cuenta))
                .isEqualTo(vinculosActiva);
        jdbc.queryForObject("select set_config('app.negocio_id', '', true)", String.class);
        assertThat(jdbc.queryForList("select * from vinculo_cliente where usuario_id=?", cuenta))
                .isEqualTo(vinculosActiva);
        assertThat(jdbc.queryForObject("""
                select count(*) from vinculo_cliente v join cliente c
                    on c.negocio_id=v.negocio_id and c.usuario_id=v.usuario_id
                where v.usuario_id=? and c.activo
                """, Integer.class, cuenta)).isZero();
    }
}
