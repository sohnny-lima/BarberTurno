# T-40 — Javadoc completo, generación y muestra

Fecha: 01/10/2026. Estado: **Bloqueada**, sin integración en main.
Rama: `tarea/T-40-javadoc-completo`. Base: `69484ffb74e7e942c75a3af3565c018efb5f815b`.

La API explícita está documentada y la muestra es utilizable. Falta resolver una contradicción de alcance:
JDK 21 exige Javadoc para nueve constructores públicos implícitos, pero solo se permiten cambios de comentarios.
Declarar esos constructores excede el límite; ocultar clases o desactivar comprobaciones reduciría la verificación.
No se aplicó ninguna de esas alternativas. Las pruebas pasan y el build estricto falla por ese motivo.

## Auditoría antes y después

El analizador usa el AST de Java y DocTrees, sin resolución de dependencias ni red.
Evalúa el cuerpo descriptivo del comentario (sin tags) y marca trivial si tiene tres palabras o menos.

No se fuerza el resultado a 259: el AST incluye declaraciones anidadas y en la misma línea.

Los nueve constructores sintetizados no pertenecen a las declaraciones explícitas del AST parseado:
sus avisos de doclint siguen pendientes; la cifra cero del AST no demuestra cero avisos de todo el build.
Doclint comprobó también componentes de records, constantes, parámetros y retornos; no quedan avisos
por ellos. Se añadieron comentarios a tres campos privados de NegocioException para la documentación
que el doclet genera sobre su serialización como excepción.

Analizador utilizado, guardado temporalmente como Auditoria.java y ejecutado con Java 21:

~~~powershell

# Segundo argumento: limita el recuento a modificadores public/protected explícitos.
& "$env:JAVA_HOME\bin\java.exe" Auditoria.java backend/src/main/java explicitos
~~~

~~~java
import java.nio.file.*;
import java.util.*;
import javax.tools.*;
import javax.lang.model.element.Modifier;
import com.sun.source.tree.*;
import com.sun.source.util.*;
public class Auditoria {
 public static void main(String[] args) throws Exception {
  var compiler = ToolProvider.getSystemJavaCompiler();
  try(var manager = compiler.getStandardFileManager(null, null, java.nio.charset.StandardCharsets.UTF_8)) {
   var files = Files.walk(Path.of(args[0])).filter(p -> p.toString().endsWith(".java")).sorted().toList();
   var task = (JavacTask) compiler.getTask(null, manager, null, List.of("-proc:none"), null, manager.getJavaFileObjectsFromPaths(files));
   var units = task.parse(); var docs = DocTrees.instance(task); var positions = docs.getSourcePositions();
   int[] count = {0,0,0};
   for (var unit : units) new TreePathScanner<Void,Void>() {
    void check(Tree tree, Set<Modifier> mods) {
     boolean api = mods.contains(Modifier.PUBLIC) || mods.contains(Modifier.PROTECTED);
     if (tree instanceof MethodTree && getCurrentPath().getParentPath().getLeaf() instanceof ClassTree parent && parent.getKind() == Tree.Kind.INTERFACE) api = args.length > 1 ? mods.contains(Modifier.PUBLIC) || mods.contains(Modifier.PROTECTED) : !mods.contains(Modifier.PRIVATE);
     if (!api) return;
     var doc = docs.getDocCommentTree(getCurrentPath());
     long start = positions.getStartPosition(unit, tree);
     String name = tree instanceof ClassTree c ? c.getSimpleName().toString() : ((MethodTree)tree).getName().toString();
     String desc = doc == null ? "" : doc.getFullBody().toString().replaceAll("<[^>]*>", " ");
     int words = desc.isBlank() ? 0 : desc.strip().split("\\s+").length;
     count[0]++; if(doc == null) count[1]++; else if(words <= 3) count[2]++;
     System.out.println(Path.of(unit.getSourceFile().toUri()).getFileName()+"|"+start+"|"+name+"|"+(doc==null?"SIN":words<=3?"TRIVIAL":"OK")+"|"+desc.replace('\n',' ')+"|"+(tree instanceof MethodTree m ? m.getParameters().stream().map(v -> v.getName().toString()).collect(java.util.stream.Collectors.joining(",")) : "")+"|"+(tree instanceof MethodTree m ? String.valueOf(m.getReturnType()) : "CLASS"));
    }
    @Override public Void visitClass(ClassTree tree, Void p) { check(tree, tree.getModifiers().getFlags()); return super.visitClass(tree,p); }
    @Override public Void visitMethod(MethodTree tree, Void p) { check(tree, tree.getModifiers().getFlags()); return super.visitMethod(tree,p); }
   }.scan(unit,null);
   System.out.println("TOTAL="+count[0]+" SIN="+count[1]+" TRIVIALES="+count[2]);
  }
 }
}
~~~

~~~javascript

const fs = require('node:fs');
const path = require('node:path');
const { execFileSync } = require('node:child_process');
const base = '69484ffb74e7e942c75a3af3565c018efb5f815b';
const archivos = execFileSync('git', ['ls-tree', '-r', '--name-only', base,
  '--', 'backend/src/main/java'], { encoding: 'utf8' }).trim().split('\n');
function sinJavadoc(texto) {
  return [...texto.matchAll(/"""[\s\S]*?"""|"(?:\\.|[^"\\])*"|'(?:\\.|[^'\\])*'|\/\*\*[\s\S]*?\*\/|\s+|[\s\S]/g)]
    .map(m => m[0]).filter(t => !t.startsWith('/**') && !/^\s+$/.test(t)).join('');
}
let total = 0;
for (const archivo of archivos.filter(f => f.endsWith('.java'))) {
  const antes = execFileSync('git', ['show', `${base}:${archivo}`], { encoding: 'utf8' });
  const despues = fs.readFileSync(archivo, 'utf8');
  if (sinJavadoc(antes) !== sinJavadoc(despues)) throw new Error(`Diferencia: ${archivo}`);
  total++;
}
console.log(`Fuentes comparadas: ${total}; diferencias fuera de Javadoc: 0`);
~~~

## Incidencias y decisiones menores

1. Fallo de preparación del sandbox (`setup refresh had errors`): comandos ejecutados con escalación
   revisada automáticamente, sin tocar ACL, propietarios o configuración. La revisión rechazó dos
   actualizaciones abreviadas de la tabla por ambigüedad con la dependencia T-13; se corrigieron
   usando exclusivamente la fila completa de T-40 y una ruta raíz comprobada. Nada quedó bloqueado por aprobación.
2. Primer verify: 679 pruebas pasaron, pero JaCoCo encontró clases no coincidentes con sus datos.
   Salida resumida del fallo:

   ~~~text
   [WARNING] Classes in bundle 'barberturno' do not match with execution data.
   [WARNING] Rule violated for package pe.barberturno.reservations: lines covered ratio is 0.16, but expected minimum is 0.70
   [WARNING] Rule violated for package pe.barberturno.scheduling: lines covered ratio is 0.47, but expected minimum is 0.70
   [ERROR] Coverage checks have not been met.
   ~~~

   Se repitió con clean verify: cobertura cumplida. El verify del worktree limpio también cumple.
   No se cambiaron umbrales ni pruebas. La prueba aislada de bytecode evita depender del target compartido.
3. Primer doclint estricto: 14 avisos (9 constructores implícitos, una constante, un throws de IOException
   y tres campos de serialización). Se corrigieron los cinco avisos documentables; quedan únicamente los nueve del bloqueo.
   La invocación inicial sin el plugin declarado produjo 67 avisos y BUILD SUCCESS; no se consideró válida.
4. `reportOutputDirectory` no es un parámetro de la meta javadoc en 3.12.0:

   ~~~text
   [WARNING] Parameter 'reportOutputDirectory' is unknown for plugin 'maven-javadoc-plugin:3.12.0:javadoc (default-cli)'
   ~~~

   Se consultó el descriptor oficial local `META-INF/maven/plugin.xml`, se sustituyó por outputDirectory
   y se documentó el subdirectorio apidocs. El aviso desapareció.
5. Generar la muestra con páginas de uso produjo un enlace a una clase no seleccionada:

   ~~~text
   HTML: 26; enlaces relativos: 492; rotos: 1
   package-use.html -> class-use/EstadoReserva.html#pe.barberturno.reservations
   ~~~

   Se regeneró desde un directorio de salida limpio con use=false: 18 HTML, 341 enlaces, 0 rotos.
6. El doclet de JDK genera algunos espacios al final de línea y CRLF en Windows. diff --check detectó:

   ~~~text
   help-doc.html:67: trailing whitespace.
   help-doc.html:72: trailing whitespace.
   PoliticaTransiciones.Resultado.html:252: trailing whitespace.
   ~~~

   Se normalizó exclusivamente el texto generado, sin alterar fuentes, binarios ni .gitattributes.
7. Los scripts temporales de edición tuvieron errores de escape (ReferenceError/SyntaxError) y un log
   ocupado por una invocación todavía activa. Se corrigieron y se esperó su finalización. No son fallos
   de la aplicación ni requirieron cambios de dependencias o configuración del equipo.
