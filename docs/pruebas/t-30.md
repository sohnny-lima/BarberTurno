## Incidencias, decisiones y hallazgos

- El primer comando aislado falló antes de ejecutar: `setup refresh had errors`.
  Se usó la escalación prevista por el encargo; la revisión automática la autorizó.
  No se cambiaron ACL, propietarios ni configuración.
- Al preparar el script visual, el corte del archivo de referencia buscó CRLF cuando
  el archivo usa LF. Falló antes de iniciar procesos; se corrigió el separador:

  ```text
  Excepción al llamar a "Substring" con "2" argumentos:
  "length ('-1') must be a non-negative value. (Parameter 'length')"
  No se encontró infraestructura CDP.
  ```

  No hubo fallos de lint, Vitest, build, verify ni del recorrido HTTP/visual.
- El runtime Node REPL del navegador integrado no estaba expuesto en las herramientas;
  se reutilizó el enfoque Edge/CDP local del proyecto, sin dependencias nuevas.
- Decisiones menores: catálogo histórico incluye inactivos; tamaño inicial 10 y opciones
  10/20/50; barras nativas con texto; datos parciales no se presentan; paginación conserva
  los filtros aplicados. La suma visible solo comprueba los datos recibidos del servidor.
- Hallazgo ya previsto en el plan: crear reservas como ADMIN sigue pendiente de T-31.
  El ensayo usa ADMIN para preparación/cancelación/reportes y CLIENTE para crear reservas.
  No se necesita cambiar diseño ni contrato para T-30. Sin bloqueos nuevos.
- Deuda de alcance: matriz completa Chromium/Firefox y axe corresponde a T-34.
  El presupuesto inicial conserva 10,20 kB de margen. Java es informativo (RA-02).
