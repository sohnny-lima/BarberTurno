**Ejecutor aislado:** el primer comando no pudo comenzar; se solicitó ejecución escalada y la revisión automática la aprobó. Se usó esa vía para las operaciones siguientes, sin cambiar ACL, propietarios ni configuración de Codex.


**fnm desde frontend:** el primer intento de activar Node allí, con la estrategia predeterminada local, terminó con código 1 antes de ejecutar ng add:

```text

```

Se consultó `fnm env --help` y se añadió `--version-file-strategy recursive`, que busca el archivo en los directorios padres. La instalación y activación de Node quedaron completas.
